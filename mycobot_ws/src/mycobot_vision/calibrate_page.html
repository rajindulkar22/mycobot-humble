Table calibration

Click the overview image, then capture the live tool pose. The camera angle changed, so the old pixel pairs are not used. Pick page

Steps

  1. Put the centre between the gripping pads on a table mark. Keep that pad centre still.
  2. Click that same point on the image. Pose age must be under 1 second.
  3. Press Capture pose. This saves the pixel and /mycobot/tool_pose_raw. It does not move the arm.
  4. Repeat at five spread-out marks, then one extra mark for the check. Cover both left-right and forward-back.
  5. Confirm table height and hover, capture the drop, then Accept only if the check error is under 12 mm.

Height, hover, and drop already saved from the last physical reading stay as starting values. They are not a new pixel map.
