Table calibration

Prefer ArUco capture (stable pixel centre). Pad auto is a fallback only. Pick page · Print marker · Overview

Steps (ArUco)

  1. Print DICT_4X4_50 id 0, tape it flat with a white margin. Clear coloured caps off the table.
  2. Put the open pad centre on the marker centre at table z ≈ 64 mm. Orange cross on overview = marker.
  3. Press Hold motors, then ArUco capture. This saves marker (u,v) + live tool pose. Do not use Auto for fit spots.
  4. Move the paper to a new place; repeat for five spread-out fits, then one check. Need span ≥ 100×80 px.
  5. Capture shared + colour drops (X ≤ ~275 mm), then Accept only if check error is OK and every fit residual is ≤ 8 mm and |z−table_z| ≤ 5.
  6. Optional: click the image + Capture pose for a manual override. Prefer ArUco.
